# COIPO CONAF Dashboard v1.1.0

## Ejecutar en Windows
1. Descomprimir el ZIP.
2. Entrar a `frontend`.
3. Ejecutar `ejecutar.bat` o usar:
   - `npm install`
   - `npm run dev`
4. Abrir la URL que indique Vite.

## Fuente de datos
El dashboard usa `frontend/public/sidco_sintetico_sur_chile_1mes_yoy.json`.
Los datos son completamente sintéticos y se incluyen solo para desarrollo y pruebas.
