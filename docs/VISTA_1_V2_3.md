## Navegación territorial

Chile → Región → Provincia → Comuna → Incendio.

Mapa y ranking comparten el mismo estado territorial.

- Hover: informa.
- Clic territorial: filtra y hace drill-down.
- Zoom manual: no filtra.
- Breadcrumb: permite volver.
- flyTo: transición animada.

## Incendios

Llama SVG dimensionada según superficie usando escala no lineal.

- Hover: tooltip compacto.
- Clic: selecciona incendio.
- Doble clic: abre Bitácora.
- Móvil: tarjeta + botón “Ver bitácora”.
