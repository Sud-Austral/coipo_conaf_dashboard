# Vista 3 · Operación y Recursos · v2.5.0

## Pregunta
¿Cómo estamos respondiendo y dónde está concentrado el esfuerzo operacional?

## Componentes
- Lectura operacional.
- KPI: recursos movilizados, personal movilizado, incendios atendidos, despacho→arribo, arribo→combate y primer ataque→control.
- Mapa operacional.
- Selección de incendio.
- Recursos asignados.
- Tiempos del evento.
- Línea de tiempo operacional.
- Replay interactivo.

## Replay
Controles:
- Play/Pausa.
- Reiniciar.
- Slider temporal.
- Estado de cada recurso por hito.

La maqueta usa datos demo para validar la experiencia. Luego debe alimentarse con `movimiento` real.

## Regla importante
La animación entre base y evento NO representa una trayectoria GPS real. Solo visualiza el avance temporal entre hitos conocidos.
